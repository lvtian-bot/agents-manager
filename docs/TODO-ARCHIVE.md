# 已发布版本的完成事项

## 0.0.5

### 新功能

- [x] 模型设置内置 DeepSeek 官方和硅基流动，也支持自定义接口。API Key 由 Obsidian 密钥存储管理，自定义连接按接口地址匹配密钥。原先通过环境变量使用模型的用户需在插件设置中填写一次 API Key，已有的自定义接口和模型名称可沿用。✅ 2026-11-27 [插件与配置](插件与配置/插件与配置.md)
- [x] 模型选择和总结提示词设置自动保存，API Key 可单独保存。GitHub 技能使用公开仓库，设置页移除了 GitHub 凭据字段。✅ 2026-11-27 [插件与配置](插件与配置/插件与配置.md)
- [x] 技能列表使用 Obsidian 原生开关管理各工具的技能链接。点击技能名称可阅读格式化正文，铅笔图标用于编辑自建技能或修改 GitHub 链接。✅ 2026-11-27 [技能管理](技能管理/技能管理.md)
- [x] 打开技能管理时后台检查更新，成功结果在同一设备上复用 24 小时。手动「检查更新」覆盖所有仓库中的 GitHub 技能，检查期间显示「检查中」。✅ 2026-11-27 [技能管理](技能管理/技能管理.md)

### Bug 修复

- [x] 指令批量分发限定在当前标签页。已同步的目标隐藏差异操作，有差异时统一显示「回收改动」「覆盖改动」「审阅合并」，推荐操作以蓝色突出。✅ 2026-11-27 [指令同步](指令同步/指令同步.md)
- [x] 技能列表对齐各仓库的列宽和分发开关，缩短操作控件的间距。确认有新版时在对应行显示「更新」，其余行收起该按钮占用的空间。检查异常入口与技能名称同行。✅ 2026-11-27 [技能管理](技能管理/技能管理.md)
- [x] 统一管理工作区的栏目导航和字号。两栏在顶部提供「刷新」，技能管理把「检查更新」放在下方的仓库操作区。操作记录、撤销入口和范围说明位于底部固定栏。✅ 2026-11-27 [插件与配置](插件与配置/插件与配置.md)
- [x] 修正指令同步的刷新位置提示及安装文档的下载链接，明确发布附件和安装目录。✅ 2026-11-27 [安装说明](../README.md)
