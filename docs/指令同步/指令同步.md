# 指令同步

用户级指令同步整篇正文。Work、Code 类型同步第一个一级标题起至第二个一级标题前的内容，项目自己的后续章节保留。类型模板可在首次创建目标时提供完整正文。打开的编辑器优先于磁盘，以便对比尚在编辑的内容。[文档处理与行级差异](../../src/instructions/documents.js)

面板将当前源和目标与上次记录比较，分别处理缺失、首次接入、内容一致、源变化和目标变化。可逐个目标分发、回收或勾选差异行后写回。登记表维护项目类型及路径，移除登记时清理相应基线。同步面板的「一键分发」同时处理全部用户级目标和已登记的 Work、Code 项目。确认前重新比对，列出待处理数量和有本地差异的目标。已同步目标跳过。遇到无效模板、项目结构错误或重复路径时整批停止。

项目清单和两份基线位于插件目录的 `sync/`。首次打开时，从库配置目录下的 `nascence-sync/`（优先）或 `agents-manager-sync/` 校验并复制旧文件。复制完成后才启用新目录，旧数据保留。

「撤销上次操作」跨面板和重启生效。单个分发、回收、双侧合并和整批分发共用一次撤销记录。撤销恢复本次涉及的文件和基线，本次新建的目标会移除。有后续编辑时先提示受影响路径。写入中断时保留操作记录，重试撤销会跳过已还原的内容。

隔离测试从真实插件命令进入，覆盖旧数据迁移、项目专属正文保留、回收失败重试、合并第二侧失败回滚、双侧撤销、混合目标批量分发和整批撤销。[自动化测试](../../test/plugin.test.cjs)
