# 指令同步

用户级指令同步整篇正文。Work、Code 类型同步第一个一级标题起至第二个一级标题前的内容，项目自己的后续章节保留。类型模板可在首次创建目标时提供完整正文。打开的编辑器优先于磁盘，以便对比尚在编辑的内容。[文档处理与行级差异](../../src/instructions/documents.js)

「指令同步」的用户级、Work、Code 标签页各自在顶部设置来源，可在库内搜索选择笔记或输入相对路径，点击「保存」后立即刷新。来源保存、用户级目标管理与插件其他页面共享配置串行队列。用户级可通过「添加目标」选择尚未添加的 Harness，Work 和 Code 可在各自页面登记项目。

用户级、Work 和 Code 的目标卡片都在左侧显示名称与路径，右侧显示同步状态和可用操作。已同步时只显示状态，文件缺失时只显示「创建目标文件」，内容一致但还没有同步记录时只显示「建立同步基线」。内容无法解析时显示原因。右上角的「×」用于移出用户级目标或移除项目登记，移除项目登记同时清理相应基线。源笔记未配置或不可用时，已有目标仍可移除。

来源和目标存在差异时，三页都按「回收改动」「覆盖改动」「审阅合并」排列双行按钮。只有目标更新时推荐回收，将目标内容写回来源。只有来源更新时推荐覆盖，将来源内容写入目标。双方都有改动或首次比对存在差异时推荐审阅合并，可逐行勾选并预览写回两侧的内容。推荐项以蓝色突出。操作和撤销完成后，各页状态会原地刷新，保留当前标签页与滚动位置。标签栏旁的「刷新」可手动重新比对指令。

底栏的「分发用户级指令」「分发 Work 项目」「分发 Code 项目」只处理点击时所在标签页的待同步目标。确认框列出本页待处理数量和有本地差异的目标，确认后再次比对本批内容。已同步目标跳过。若本页来源或目标内容无法解析，或本页目标路径与其他目标或来源重复，整批停止。

项目清单和两份基线位于插件目录的 `sync/`。首次打开时，从库配置目录下的 `nascence-sync/`（优先）或 `agents-manager-sync/` 校验并复制旧文件。复制完成后才启用新目录，旧数据保留。

操作记录旁的「撤销上次操作」使用指令同步自己的记录，在切换指令标签页或重启后仍可用。单个分发、回收、双侧合并和整批分发共用一次撤销记录。撤销恢复本次涉及的文件和基线，本次新建的目标会移除。有后续编辑时先提示受影响路径。写入中断时保留操作记录，重试撤销会跳过已还原的内容。
