# 指令同步

用户级指令同步整篇正文。Work、Code 类型同步第一个一级标题起至第二个一级标题前的内容，项目自己的后续章节保留。类型模板可在首次创建目标时提供完整正文。打开的编辑器优先于磁盘，以便对比尚在编辑的内容。[文档处理与行级差异](../../src/instructions/documents.js)

面板将当前源和目标与上次记录比较，分别处理缺失、首次接入、内容一致、源变化和目标变化。可逐个目标分发、回收或勾选差异行后写回。登记表维护项目类型及路径，移除登记时清理相应基线。覆盖前备份，基线文件使用临时文件替换。行级合并写回源和目标是两个文件操作，发生中途故障时有可能只写完一侧。[同步实现](../../src/instructions/panel.js)

现有隔离测试覆盖旧登记和基线接续、类型区块分发、备份、双方有差异时的合并，以及只在目标修改后的回收。回收测试会注入源笔记写入失败，核对源、目标和基线均保留失败前内容，确认留下备份并可重试成功。

`0.0.1` 使用隔离样例模拟了合并时第二侧写入失败。两侧均保留原文备份，同步基线仍指向上次成功同步的版本。将已写入的一侧从备份恢复后，可以重试合并。
