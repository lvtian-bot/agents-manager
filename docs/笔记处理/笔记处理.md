# 笔记处理

「AI 翻译为中文」只处理选中的外文，提示模型保留已有中文；没有选区时不发起请求。「AI 总结笔记」始终读取整篇笔记。单提示词模式不读元数据；多提示词模式读取指定属性，以属性值精确匹配已保存的规则。缺少属性或未匹配时使用备用提示词。单一提示词或备用提示词留空时使用内置提示词。提示词可通过 `{activeNote}` 引入笔记。[笔记处理实现](../../src/notes.js)

总结合并提示词和当前整篇笔记，翻译只将选中文字加入翻译提示词。插件在执行命令时把提示词发送到所选模型的接口，并从 Obsidian 密钥存储读取对应的 API Key。预设按服务匹配密钥，自定义连接按规范化后的完整接口地址匹配密钥。缺少配置或凭据时在发送请求前提示。硅基流动的跨域预检未明确放行鉴权头，插件使用桌面端 HTTPS 请求读取该服务的流式响应。插件处理流式文本和普通 JSON 响应，预览可编辑，支持放弃、替换或追加。写回前检查文件、编辑器和原文本，结束预览会中止尚未完成的请求。

自动化测试以合成笔记和模拟响应检查选区翻译、三种文献模板、默认回退、编辑后的结果写回，以及请求取消、接口错误（HTTP 错误、JSON/流内错误、网络异常、空白响应与缺少凭据）和生成期间切换笔记、修改正文或切换编辑器的写回拦截。
