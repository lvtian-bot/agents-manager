# 插件与配置

插件加载时注册工作区视图（`agents-manager-workspace`）和「AI 总结笔记」「AI 翻译为中文」「分发与回收指令」「管理技能」，并创建设置页。快捷键由 Obsidian 管理。「分发与回收指令」与「管理技能」复用同一个主界面标签页，分别切到「指令同步」和「技能管理」栏目；插件同时跟踪打开的辅助弹窗，卸载时依次关闭。[插件入口](../../src/plugin.js)、[工作区视图](../../src/workspace.js)

设置页分为三区，共用「保存设置」。库内的源笔记和模板支持按文件名或路径搜索选择，也可手动输入相对路径。[设置实现](../../src/settings.js)

- **分发与回收指令**：选择用户指令源笔记，再通过「添加目标」选择尚未添加的 Harness。卡片只显示名称，每行最多三张；右上角「×」只移出同步列表，不删除目标文件。新增目标使用内置路径，已有目标保留原路径（包括旧配置中的自定义目标）。Work、Code 项目模板仍可单独选择，具体项目在同步面板登记。
- **技能管理**：配置「用户级技能分发目标」（默认含 Claude `~/.claude/skills` 与 Antigravity `~/.gemini/config/skills`）、「项目级技能分发目标」（默认含 Claude `.claude/skills`），以及默认收起的可选「GitHub 更新凭据」环境变量名。
- **AI 总结笔记**：新库默认使用单提示词模式，只选择一份总结提示词。多提示词模式可设置匹配属性、任意多条「属性值 → 提示词笔记」规则及未匹配时使用的提示词。保存当前模式的设置不会改写另一模式已保存的配置。升级时已有规则的库沿用多提示词模式，无规则的库沿用原默认提示词。新库不按特定库内文件推断规则。
- **模型连接**：总结和选区翻译共用同一组模型设置。接口地址、模型名称和凭据环境变量名初始为空，已有的保存值会继续加载。只使用指令同步或技能管理时可以整组留空。翻译的目标语言固定为中文。

表单通过检查后才一次性保存；填写错误显示在对应行，位于折叠组时会展开该组。目标和模板沿用原有配置格式。新库的目标列表为空；检测到旧同步目录时会提供旧来源与六个用户级目标的默认值。

验证命令注册要从打包后的入口加载插件。配置改动还要覆盖新库和旧布局，尤其要检查是否意外带入真实目标。桌面测试库只填入本次生成的目标路径。
