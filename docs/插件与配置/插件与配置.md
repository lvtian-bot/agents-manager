# 插件与配置

插件加载时注册「AI 总结或翻译」和「分发与回收指令」，并创建设置页。快捷键由 Obsidian 管理。插件跟踪打开的弹窗，卸载时依次关闭；同一插件实例同时只开一个同步面板。[插件入口](../../src/plugin.js)

设置页分为两区，共用「保存设置」。库内的源笔记和模板支持按文件名或路径搜索选择，也可手动输入相对路径。[设置实现](../../src/settings.js)

- **分发与回收指令**：选择用户指令源笔记，逐行添加或移除工具名称与本机目标文件，再选择 Work、Code 项目模板。用户级目标支持绝对路径或以 `~/` 开头的路径；具体项目仍在同步面板登记。
- **AI 总结或翻译**：常用项为默认总结模板和翻译方向。「按类型指定总结模板」内设置笔记类型属性及各类型对应的模板；「模型连接」内设置接口、模型名及凭据环境变量名。这两组默认折叠。

表单通过检查后才一次性保存；填写错误显示在对应行，位于折叠组时会展开该组。目标和模板沿用原有配置格式。新库的目标列表为空；检测到旧同步目录时会提供旧来源与六个用户级目标的默认值。

验证命令注册要从打包后的入口加载插件。配置改动还要覆盖新库和旧布局，尤其要检查是否意外带入真实目标。桌面测试库只填入本次生成的目标路径。
