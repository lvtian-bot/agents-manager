# 插件与配置

插件加载时注册「AI 总结或翻译」和「分发与回收指令」，并创建设置页。快捷键由 Obsidian 管理。插件跟踪打开的弹窗，卸载时依次关闭；同一插件实例同时只开一个同步面板。[插件入口](../../src/plugin.js)

设置页接受模型接口、模型名、凭据环境变量名、翻译方向、笔记类型属性及模板映射，以及用户级目标与 Work、Code 指令源。用户保存后通过插件数据接口持久化。用户级目标允许绝对路径或以 `~/` 开头的路径。新库的目标列表为空；检测到旧同步目录时会提供旧来源与六个用户级目标的默认值。[设置实现](../../src/settings.js)

验证命令注册要从打包后的入口加载插件。配置改动还要覆盖新库和旧布局，尤其要检查是否意外带入真实目标。桌面测试库只填入本次生成的目标路径。
