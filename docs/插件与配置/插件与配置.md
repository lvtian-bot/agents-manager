# 插件与配置

插件加载时注册工作区视图（`agents-manager-workspace`）和「AI 总结笔记」「AI 翻译为中文」「分发与回收指令」「管理技能」，并创建设置页。快捷键由 Obsidian 管理。点击 Obsidian 左侧工具栏的「多 Agent 管理」图标即可打开主界面标签页。新打开时进入「指令同步」，切回已打开的标签页时保留当前栏目。「分发与回收指令」与「管理技能」复用同一个标签页，分别切到「指令同步」和「技能管理」栏目；插件同时跟踪打开的辅助弹窗，卸载时依次关闭。[插件入口](../../src/plugin.js)、[工作区视图](../../src/workspace.js)

工作区按实际重叠范围避让 Obsidian 状态栏，使「指令同步」和「技能管理」的底部操作按钮可点击。状态栏隐藏或工作区与其错开时，底部恢复原有布局。

工作区共用一套字号。来源、项目和技能名称使用正文字号，标签页、状态和操作按钮使用接近正文字号的大小，页首说明、次要路径及操作记录使用小字号。字号基于 Obsidian 主题的界面字体变量。

设置页直接展示「AI 总结笔记」和「模型连接」两组设置，共用「保存设置」。笔记选择器支持按文件名或路径搜索，也可手动输入库内相对路径。[设置实现](../../src/settings.js)

- **AI 总结笔记**：新库默认使用单提示词模式，只选择一份总结提示词。多提示词模式可设置匹配属性、任意多条「属性值 → 提示词笔记」规则及未匹配时使用的提示词。保存当前模式的设置不会改写另一模式已保存的配置。升级时已有规则的库沿用多提示词模式，无规则的库沿用原默认提示词。新库不按特定库内文件推断规则。
- **模型连接**：总结和选区翻译共用同一组模型设置。接口地址、模型名称和凭据环境变量名初始为空，已有的保存值会继续加载。只使用指令同步或技能管理时可以整组留空。翻译的目标语言固定为中文。

表单通过检查后才一次性保存。填写错误显示在对应行，焦点会移到需修正的输入框。指令来源及分发目标在各功能面板中管理，沿用原有配置格式，并与设置页共用插件配置串行队列。每个页面只保存自己管理的字段。新库的用户指令目标为空，技能分发目标默认仅含 Claude（用户级 `~/.claude/skills`、项目级 `.claude/skills`）。检测到旧同步目录时会提供旧来源与六个用户级指令目标的默认值。

验证命令注册要从打包后的入口加载插件。配置改动还要覆盖新库和旧布局，尤其要检查是否意外带入真实目标。桌面测试库只填入本次生成的目标路径。
