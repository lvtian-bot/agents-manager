# Agents Manager（多 Agent 管理）

面向同时使用多个 Agent 的人，管理可跨工具共享的用户指令、项目规范与 Agent 技能，并保留各项目自己的内容。配套提供 Obsidian 笔记总结和选区翻译。

| 命令 | 插件行为 |
| --- | --- |
| 分发与回收指令 | 在「指令同步」中比对源笔记、目标文件和上次同步记录，支持逐个分发、按当前标签页批量分发、回收、逐行合并及撤销上次操作。 |
| 管理技能 | 在「技能管理」列表中创建、查看和编辑自建技能，导入、检查和更新 GitHub 技能，并按工具分发用户级、当前 Obsidian 仓库和已登记项目的技能。支持整目录链接转为逐个链接。 |
| AI 总结笔记 | 总结当前整篇笔记。可使用单一提示词，也可按自定义元数据属性匹配不同的提示词。 |
| AI 翻译为中文 | 只把选中的外文译成中文，不使用总结提示词。 |

四项命令的快捷键可分别绑定。原「AI 总结或翻译」的快捷键需重新绑定到所需命令。运行需要 Obsidian 桌面版，最低版本见 [manifest.json](manifest.json)。

## 安装

1. 在 [GitHub Releases](https://github.com/lvtian-bot/obsidian-agents-manager/releases) 打开所需版本，展开「Assets」，下载 `main.js` 和 `manifest.json`。
2. 在知识库根目录下创建 `.obsidian/plugins/agents-manager/`，放入这两个文件。如果知识库使用自定义配置目录，把路径里的 `.obsidian` 换成该目录名称。
3. 重新打开 Obsidian，在「设置 → 第三方插件」启用「Agents Manager」。在「指令同步」的用户级、Work 和 Code 标签页选择对应的源笔记或模板，并在「指令同步」「技能管理」面板中添加需要分发的 Harness 目标。
4. 使用 AI 总结或翻译时，在「模型设置」选择「DeepSeek 官方」「硅基流动」或「自定义连接」。自定义连接需要填写兼容 Chat Completions 的完整接口地址和模型名称。填入对应的 API Key 并点击旁边的「保存」。只使用指令同步或技能管理时，可以留空。

## 本机文件与联网

- **分发与回收指令**会在本机读取和写入库内指令笔记，以及你添加的 Agent 指令文件和已登记项目的 `AGENTS.md`。批量分发只处理当前标签页的待同步目标。用户级分发整份指令正文，Work 和 Code 分别向本类型的项目分发工作规范。确认时列出本页存在本地差异的目标。插件目录的 `sync/` 保存项目清单、同步记录和最近一次操作的原文。可在面板中整批撤销。指令同步可离线使用。
- **管理技能**会在本机读取和写入用户级 `~/.agents/skills`、当前 Obsidian 仓库与已登记项目 `.agents/skills` 中的 `SKILL.md` 及技能文件，并在你配置的 Harness 技能目录建立或清理指向单个技能的目录联接／符号链接。技能来源与撤销快照保存在插件目录的 `sync/`。GitHub 技能来自公开仓库。进入技能管理时，插件通过 GitHub API 在后台检查已登记来源的最新提交，成功结果在本机复用 24 小时。「检查更新」可立即重查。点击「导入」或「更新」时，插件通过 `raw.githubusercontent.com` 下载技能文件。
- **AI 总结笔记**会将当前整篇笔记及总结提示词发送到你选择的模型接口。**AI 翻译为中文**会将选中的文字及翻译提示词发给该接口。账号、费用和数据处理规则取决于所选服务。API Key 保存在 Obsidian 密钥存储中，预设按服务分别保存，自定义连接按完整接口地址分别保存。

## 开发入口

项目根目录执行 `npm ci` 安装依赖。使用 `npm test` 构建并运行隔离测试；使用 `npm run test:vault` 生成独立桌面测试库。单独构建使用 `npm run build`。测试和构建不需要真实模型凭据。
