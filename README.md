# Agents Manager（多 Agent 管理）

面向同时使用多个 Agent 的人，管理可跨工具共享的用户指令、项目规范与 Agent 技能，并保留各项目自己的内容。配套提供 Obsidian 笔记总结和选区翻译。

| 命令 | 插件行为 |
| --- | --- |
| 分发与回收指令 | 在主界面标签页打开「指令同步」，比对源笔记、目标文件和上次同步记录，支持逐个或一键分发、回收、行级合并及撤销上次操作。 |
| 管理技能 | 在主界面标签页打开「技能管理」，查看与检查用户级、当前 Obsidian 仓库及已登记项目技能，编辑自建 `SKILL.md`，按单个技能建立软链接分发（含整目录链接转为逐个链接），以及检查和更新 GitHub 技能。 |
| AI 总结笔记 | 总结当前整篇笔记。可使用单一提示词，也可按自定义元数据属性匹配不同的提示词。 |
| AI 翻译为中文 | 只把选中的外文译成中文，不使用总结提示词。 |

四项命令的快捷键可分别绑定。原「AI 总结或翻译」的快捷键需重新绑定到所需命令。运行需要 Obsidian 桌面版，最低版本见 [manifest.json](manifest.json)。

## 安装

1. 从 [GitHub Releases](https://github.com/lvtian-bot/agents-manager/releases) 下载同一版本的 `main.js` 和 `manifest.json`。
2. 在知识库的 Obsidian 配置目录下创建 `plugins/agents-manager/`，放入这两个文件。配置目录默认为 `.obsidian`。
3. 重新打开 Obsidian，在「设置 → 第三方插件」启用「Agents Manager」，然后在插件设置中填写指令源和目标。
4. 使用 AI 总结或翻译时，填写兼容 Chat Completions 的完整接口地址、模型名称和凭据环境变量名。三个字段初始为空。只使用指令同步或技能管理时，模型连接可整组留空。

## 本机文件与联网

- **分发与回收指令**会在本机读取和写入库内指令笔记，以及你添加的 Agent 指令文件和已登记项目的 `AGENTS.md`。访问库外文件用于在多个 Agent 之间同步共用指令。一键分发覆盖已配置的用户级目标和所有登记的 Work、Code 项目。确认时列出存在本地差异的目标。插件目录的 `sync/` 保存项目清单、同步记录和最近一次操作的原文。可在面板中整批撤销。指令同步可离线使用。
- **管理技能**会在本机读取和写入用户级 `~/.agents/skills`、当前 Obsidian 仓库与已登记项目 `.agents/skills` 中的 `SKILL.md` 及技能文件，并在你配置的 Harness 技能目录建立或清理指向单个技能的目录联接／符号链接。技能来源与撤销快照保存在插件目录的 `sync/`。只有在你手动点击「检查更新」或「更新」时，插件才会请求 GitHub API 或 `raw.githubusercontent.com` 拉取公开（或通过环境变量凭据授权）的技能仓库信息；可选 GitHub 凭据只保存环境变量名。
- **AI 总结笔记**会将当前整篇笔记及总结提示词发送到你配置的模型接口。**AI 翻译为中文**会将选中的文字及翻译提示词发给该接口。模型服务由你选择，账号、费用和数据处理规则取决于该服务。插件从指定环境变量读取凭据，在请求中用它鉴权，插件设置只保存变量名。

## 开发入口

项目根目录执行 `npm ci` 安装依赖。使用 `npm test` 构建并运行隔离测试；使用 `npm run test:vault` 生成独立桌面测试库。单独构建使用 `npm run build`。测试和构建不需要真实模型凭据。
